The first release of Tollgate: a lightweight AI gateway for coding agents. One Go binary controls cost, rate limits and failover for the Anthropic and OpenAI APIs.

Status: alpha. The configuration format can change before v1.0.

## Highlights

- **Passthrough proxy** for Anthropic `/v1/messages` and OpenAI `/v1/chat/completions`, with streaming. Streams pass through byte for byte.
- **Budgets and rate limits** for each tenant, month and agent session, with a memory store or a shared Redis store.
- **Failover** to ordered targets before the first response byte, with retries, a retry budget and circuit breakers. Vertex AI and Ollama targets.
- **Agent features**: derived session IDs, sticky routing with cache loss reports, an opt-in response cache and personal data redaction.
- **Observability**: the cost of each request in a JSONL usage file, Prometheus metrics, OpenTelemetry traces and a Grafana dashboard.
- **Embedded dashboard** on the admin port, with overview, sessions, providers and keys pages.

See [CHANGELOG.md](https://github.com/ykakade/tollgate/blob/v0.1.0/CHANGELOG.md) for the full list.

## Breaking changes

None. This is the first release.

## Install

This release has binaries for Linux on amd64 and arm64. Each archive has `tollgate` and the `fakeprovider` test server.

```sh
VERSION=0.1.0
ARCH=amd64 # or arm64
curl -fsSLO "https://github.com/ykakade/tollgate/releases/download/v${VERSION}/tollgate_${VERSION}_linux_${ARCH}.tar.gz"
tar -xzf "tollgate_${VERSION}_linux_${ARCH}.tar.gz" tollgate fakeprovider
./tollgate version
```

On other systems, install with Go: `go install github.com/ykakade/tollgate/cmd/tollgate@v0.1.0`.

## Verify

Each archive has a GitHub build provenance attestation:

```sh
gh attestation verify "tollgate_${VERSION}_linux_${ARCH}.tar.gz" --repo ykakade/tollgate
```

The file `checksums.txt` has a keyless cosign signature in `checksums.txt.sigstore.json`.
See [Install](https://github.com/ykakade/tollgate#install) for the cosign command.
