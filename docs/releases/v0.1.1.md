A patch release of Tollgate. It builds with Go 1.27.4, which has the fix for GO-2026-6859 in `net/http`, and it adds the `tollgate demo` command.

Status: alpha. The configuration format can change before v1.0.

## Highlights

- **Security fix**: the binaries build with Go 1.27.4. The v0.1.0 binaries use Go 1.27.3, which has GO-2026-6859 in `net/http`. Update to this release.
- **`tollgate demo`**: one command starts fake providers in the same process, 7 days of synthetic usage, live agent-like sessions, and the dashboard. It needs no API key, no clone, no Node.js, and no Docker.
- **Fixed demo data**: the synthetic history uses the price table in the binary and has no events after the start time of the demo.
- **Documentation**: a searchable documentation site, a quick start guide, a launch video, and a new README.
- **Fuzz tests**: CI runs all 4 fuzz targets, with `FuzzMask` in `internal/redact`.

See [CHANGELOG.md](https://github.com/ykakade/tollgate/blob/v0.1.1/CHANGELOG.md) for the full list.

## Breaking changes

None.

## Install

This release has binaries for Linux on amd64 and arm64. Each archive has `tollgate` and the `fakeprovider` test server.

```sh
VERSION=0.1.1
ARCH=amd64 # or arm64
curl -fsSLO "https://github.com/ykakade/tollgate/releases/download/v${VERSION}/tollgate_${VERSION}_linux_${ARCH}.tar.gz"
tar -xzf "tollgate_${VERSION}_linux_${ARCH}.tar.gz" tollgate fakeprovider
./tollgate version
```

On other systems, install with Go: `go install github.com/ykakade/tollgate/cmd/tollgate@v0.1.1`.

To see Tollgate work with no API key, run `tollgate demo` and open `http://127.0.0.1:9090`.

## Verify

Each archive has a GitHub build provenance attestation:

```sh
gh attestation verify "tollgate_${VERSION}_linux_${ARCH}.tar.gz" --repo ykakade/tollgate
```

The file `checksums.txt` has a keyless cosign signature in `checksums.txt.sigstore.json`.
See [Install a release binary](https://github.com/ykakade/tollgate/blob/v0.1.1/docs/quickstart.md#install-a-release-binary) for the cosign command.
