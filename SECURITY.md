# Security policy

This page tells you how to report a security problem in Tollgate.

## Supported versions

Tollgate has no release yet. After the first release, only the latest minor version gets security fixes.

| Version | Security fixes |
| --- | --- |
| No release yet | Not applicable |

## Report a problem

Do not report security problems in public issues, discussions, or pull requests. Other people can then use the problem before a fix is available.

1. Go to [private vulnerability reporting](https://github.com/ykakade/tollgate/security/advisories/new).
2. Describe the problem, the affected version, and the steps to reproduce it.
3. Do not include real API keys or real prompts.

Result: The maintainer gets a private report. The maintainer replies in the advisory and tells you about the fix and the release.

If you cannot use GitHub, open a public issue that asks for a private contact. Do not include details of the problem in the issue.
